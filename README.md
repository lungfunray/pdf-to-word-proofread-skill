# PDF 转 Word 校对

一个用于完整转换 PDF 为可编辑 Word 的 Agent Skill，面向扫描书籍、历史档案及需要对照原文校对的材料。

## 工作流程

1. 检查 PDF 的页面范围、文字层、版式和原印刷页码。
2. 提取或识别全文，保留原文用字、结构、注释和跨页续文。
3. 尽量重建原页尺寸、标题、段落、表格、行距与分页。
4. 识别存疑的文字标红，必要时用批注记录候选字。
5. 每页添加红色 PDF 页序及书内页码，并链接回源 PDF 的对应页。
6. 默认逐页核对；用户明确要求跳过时，直接交付并说明未完成最终检查。

## 使用

将此仓库中的 `SKILL.md`、`agents/` 和 `references/` 放入个人技能目录下的 `pdf-to-word-proofread/` 文件夹，然后使用：

```text
$pdf-to-word-proofread 把这个 PDF 完整转换为可编辑 Word，保留原版式，疑字和原页码标红，页码链接回原 PDF 对应页。
```

本仓库是工作流程与指令，不自带 OCR 模型或转换引擎。执行时使用所在环境可用的 PDF、Word、OCR 和渲染工具。扫描字形与字体可能只能近似重建，不能未经核对声称像素级一致。

本地 PDF 页码链接常用 `#page=N` 参数，但实际跳页取决于 Word、系统文件关联和 PDF 阅读器。流程要求区分“链接已写入”和“点击跳页已验证”，不能混为一谈。

## 文件

- `SKILL.md`：转换与校对流程。
- `agents/openai.yaml`：技能显示信息。
- `references/pdf-page-links.md`：页码链接构造、验证及兼容性处理。

仓库不包含用户原始文档、转换产物或账号凭据。
